# AnywhereTry · AI 实时试穿服装网站

参照 **Anywear: Live Virtual Try-On** 的体验：顾客打开摄像头，衣服**实时“穿”在视频里的自己身上**，转身、抬手都跟着动，点一下就换下一件。

**网站只负责展示和实时试穿，不在线收款**：顾客点“微信下单”，看到店主微信号/二维码和一段可复制的下单信息（商品、尺码、价格），加微信后完成付款和发货。

## 页面

| 地址 | 内容 |
| --- | --- |
| `/` | 首页：主视觉 + 分类 + 商品列表 |
| `/product.html?id=…` | 商品详情：选尺码、实时试穿、微信下单 |
| `/tryon/?id=…` | 实时试穿：摄像头 → AI 实时换装视频，底部切换款式，可直接“微信下单这件” |
| `/tryon/check.html` | 网络检测：测当前网络能否流畅使用实时试穿（给国内用户测试用） |

手机和电脑浏览器都能用。

## 原理

```
浏览器
 ├─ 首页 / 商品页 (server/web)      ──► GET /api/site, /api/products
 └─ 实时试穿页 (server/h5)
      ├─ getUserMedia 打开摄像头
      ├─ POST /api/realtime-token   ──► 后端用永久 Key 签发 60 秒短期令牌
      └─ Decart SDK (WebRTC)        ──摄像头视频流──► Decart Lucy VTON 实时模型（云端 GPU）
                                    ◄──已换装的视频流──
         换衣服：rtc.setImage(服饰图)，不断线即时切换
```

- 永久 API Key 只在服务器；令牌限定模型、可限定来源域名、**服务端强制单次时长上限**（默认 90 秒）；按 IP 每日次数限制；页面切到后台立即断开，不再计费、不再传画面。
- 没配置 `DECART_API_KEY` 时是**演示模式**：试穿页只显示摄像头原画，方便先调页面。

## 本地运行

```bash
cd server
cp .env.example .env
npm install
npm start
```

打开 http://localhost:3000 。在电脑上 `localhost` 可以直接用摄像头；用手机访问需要 https（见下方部署）。

## 需要你改的地方

| 改什么 | 在哪里 |
| --- | --- |
| 店名、下单微信号、下单说明 | `server/.env` 里的 `SHOP_NAME`、`ORDER_WECHAT_ID`、`ORDER_NOTE` |
| 微信二维码 | 替换 `server/public/contact/wechat-qr.png` |
| 商品 | `server/src/products.json`（名称、价格、分类、尺码、描述、`tryonPrompt` 英文描述） |
| 商品图 / 试穿参考图 | `server/public/garments/`：白底或干净背景、单件平铺、主体完整（现在是占位图） |
| AI 实时试穿 | `server/.env` 填 `DECART_API_KEY`（在 https://platform.decart.ai 获取） |

## 部署上线

1. 一台云服务器（Node.js 20+），`npm install && npm start`，用 pm2 等守护进程。
2. 前面挂 Nginx：**必须 https**（浏览器只在 https 下允许摄像头），并开启 gzip/brotli（试穿页脚本约 1.1MB，压缩后小很多）。
3. `.env` 里 `TRYON_PUBLIC_ORIGIN` 填网站地址，如 `https://www.example.com`，令牌只能从这个域名使用。
4. **服务器放在哪里**：
   - 国内服务器：访问快，但域名必须做 **ICP 备案**；
   - 香港/海外服务器：不用备案，国内访问会慢一些。实时视频本身就要连到 Decart 的海外机房，所以网站放香港是一个折中选择。

## 在微信里分享

链接发到微信会在**微信内置浏览器**打开：
- 浏览商品、微信下单弹窗都正常；
- 实时试穿需要摄像头，部分手机的微信内置浏览器不支持，页面会提示顾客点右上角「···」→「在浏览器打开」。
- 域名如果被投诉，可能被微信拦截访问，注意内容合规。

## ⚠️ 面向国内用户的风险（做网站同样适用）

**先测再说**：部署后让国内的朋友打开 `/tryon/check.html`（网络检测页），分别用 Wi-Fi 和 4G/5G 测一次，点“复制检测结果”发回来。前三项免费；第四项会真实连接模型约 12 秒（约 0.24 美元），测出“动作 → 看到换装画面”的真实延迟。

1. **延迟**：Decart 服务器在境外，国内用户的视频流要跨境往返，可能比官方演示卡。先找几位国内朋友用 4G/5G 和家里宽带实测。
2. **人脸视频出境**：摄像头画面含人脸（敏感个人信息），实时传到境外属于《个人信息保护法》下的数据出境。页面已有单独同意勾选框；规模做大后需要隐私政策和出境合规手续。
3. **生成式 AI 监管**：面向国内公众提供生成式 AI 服务有备案和标识要求（页面已标注“AI 实时效果 · 仅供参考”），正式推广前建议咨询法务。

后续如果找到国内的实时视频试穿服务，只需改 `server/src/index.js` 的令牌签发和 `server/h5/app.js` 的连接部分。

## 目录结构

```
anywheretry/
├── server/
│   ├── src/index.js           后端：店铺信息、商品、实时令牌、限流
│   ├── src/products.json      商品数据
│   ├── web/                   首页、商品详情页、微信下单弹窗
│   ├── h5/                    实时试穿页源码（打包到 public/tryon/）
│   └── public/
│       ├── garments/          商品图 / 试穿参考图
│       └── contact/           微信二维码
└── miniprogram/               微信小程序版本（暂不使用，以后有营业执照后可用 web-view 套用同一个试穿页）
```

## 成本

Decart 官方价格：`lucy-vton-3.6` / `lucy-vton-3.5` 标准模式 **0.02 美元/秒**（720p），fast 模式 0.04 美元/秒（仅美国区）。一次 90 秒试穿约 1.8 美元（约 13 元人民币）。务必保留单次时长上限和每日次数限制。
